# Практическое задание 1

Группа СДП-ПИ-241.
Команда из одного участника: Крышалович Дмитрий Павлович.
Название проекта: "Крокодил-онлайн" (может поменяется).
Функциональные требования к проекту:
1. Создание и присоединение к игровым комнатам — публичным (случайный подбор) и приватным (по коду/ссылке-приглашению).
2. Вход в игру без регистрации (гостевой режим) и/или регистрация с сохранением профиля и статистики.
3. Игровой раунд: выбор ведущего (по кругу или случайно), выбор слова ведущим (случайное слово или выбор из нескольких предложенных вариантов).
4. Интерактивный холст для рисования (HTML5 Canvas), синхронизируемый в реальном времени у всех игроков комнаты.
5. Чат для отправки вариантов ответа с автоматической проверкой правильности ответа и начислением очков (чем быстрее угадал — тем больше очков).
6. Таймер раунда с отображением оставшегося времени; постепенные подсказки (например, открытие букв слова через равные промежутки).
7. Таблица очков/лидеров в рамках комнаты и по итогам игры.
8. Настройки комнаты (владельцем): число раундов, время на раунд, максимум игроков, язык слов, приватность комнаты.
9. Управление словами: стандартные наборы слов + пользовательские колоды слов (CRUD для владельца комнаты/администратора).
10. Возможно, профиль пользователя со статистикой сыгранных игр.
11. Роли: игрок; владелец комнаты (базовая модерация — кик/бан в своей комнате); администратор платформы (CRUD слов и категорий, модерация пользователей).
12. Адаптивный интерфейс — корректная работа и на десктопе, и на мобильных устройствах.

Технологический стек:
- Backend: PHP.
- Frontend: HTML5, CSS3 (с media-запросами для адаптивности), JavaScript; фреймворк — на выбор, кроме React (рассматриваются Vue.js / Alpine.js).
- Рисование: HTML5 Canvas API.
- Реальное время: AJAX/long polling к PHP-бэкенду как базовый вариант; при необходимости — отдельный WebSocket-сервис для синхронизации холста и чата.
- База данных: реляционная (MySQL/PostgreSQL) — пользователи, комнаты, результаты игр, наборы слов; нереляционная (MongoDB/Redis) — состояние активных игровых комнат в реальном времени, история ходов и сообщений чата.
- Хостинг: уточняется.
- Система контроля версий: Git/GitHub.

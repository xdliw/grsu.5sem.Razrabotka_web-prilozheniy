## Как проверить пункты 🔲 (сделать самостоятельно в браузере)

1. **Архитектура/технологии по сети.** Открыть сайт → DevTools (F12) → вкладка **Network** → перезагрузить страницу (Ctrl+R). Посмотреть:
   - заголовки первого запроса (Response Headers: `Server`, `X-Powered-By` — иногда выдают бэкенд);
   - вкладку **WS** — если во время игры там появляется активное соединение, значит используется WebSocket для синхронизации холста/чата в реальном времени; если WS пусто, но в Network во время игры видны повторяющиеся XHR-запросы — это long polling;
   - вкладку **Sources** — имена файлов бандла (`_next/`, `vue`, `socket.io.js`, `webpack` и т.п.) подсказывают фреймворк.

2. **Семантические элементы HTML5.** DevTools → **Elements** → Ctrl+F (поиск по DOM) → ввести по очереди `header`, `nav`, `main`, `section`, `article`, `aside`, `footer` — сколько раз каждый встречается на странице.

3. **Семантические классы у div.** Если тегов из п.2 почти нет, а вёрстка на div — посмотреть в Elements имена классов у крупных блоков (например `class="header"`, `class="game-container"`, `class="chat-box"`) и выписать 2-3 примера.

4. **Адаптивность.** DevTools → **Toggle device toolbar** (Ctrl+Shift+M) → проверить на нескольких ширинах (375px телефон, 768px планшет, 1024-1440px десктоп) — что перестраивается. Также в **Sources** можно открыть CSS-файлы и поискать `@media` — посмотреть какие брейкпоинты заданы.

5. **Lighthouse.** DevTools → вкладка **Lighthouse** → выбрать Mobile или Desktop и категории (Performance, Accessibility, Best Practices, SEO) → Analyze page load. **Обязательно зафиксировать в отчёте условия проверки**: тип интернета (Wi-Fi/мобильный интернет/LAN) и место (дом/общежитие/университет) — результаты Lighthouse сильно зависят от реальной скорости соединения в момент теста, даже с учётом встроенного троттлинга.

6. **LocalStorage и Cookies.** DevTools → вкладка **Application** → слева **Local Storage** и **Cookies** → открыть домен сайта → посмотреть какие ключи там хранятся (никнейм, настройки, токен авторизации и т.п.).

7. **Маркетинг и аналитика.** DevTools → **Network** → в поле **Filter** по очереди вписать: `analytics`, `metrika`, `facebook`, `pixel`, `tagmanager`, `hotjar`, `doubleclick` — и посмотреть, какие запросы срабатывают (особенно после клика "Accept" на баннере cookies, если он есть).
